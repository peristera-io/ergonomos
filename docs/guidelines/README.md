# Guidelines

Conventions we have *discovered* while building ergonomos — patterns worth
repeating and pitfalls worth avoiding. Unlike ADRs (which record one-off
decisions), guidelines are living, reusable rules of thumb promoted from real
experience.

When a guideline emerges, add a short focused file here (e.g.
`error-handling.md`, `naming.md`) and link it from `CLAUDE.md` if it should be
read by every agent.

Nothing here yet — guidelines are added as they prove themselves, not upfront.
